Shows all of the time zones for the US/Canada, UTC, London, and Queensland.

Highlights the current computer time zone.


PowerShell version can be ran as is.
The Python script has a dependency on PySide6 and that needs to be installed first.


Any issues with displaying, remove the TimeZones.json file in your profile.
